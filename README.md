# AI 产品作品集

围绕真实使用需求，我把想法落成可操作的产品，并持续打磨交互、AI 对话和记录体验。这里整理了三个项目的产品介绍与设计思路。

| 项目 | 产品方向 | 了解与体验 |
| --- | --- | --- |
| **Arcana** | 以塔罗为入口，探索有性格、有记忆的 AI 互动体验；围绕持续追问和可管理的长期记忆迭代 | [产品介绍](projects/arcana/README.md) · [在线体验](https://arcana.ououm.com) |
| **Lucky 的小窝** | 网页与 AI 助手共享一只虚拟橘猫，让状态、互动与长期记录在两个入口之间延续 | [产品介绍](projects/lucky/README.md) |
| **Raven Tarot** | 将塔罗抽牌与历史记录接入 AI 对话，同时提供可以亲自选牌的网页体验 | [产品介绍](projects/raven-tarot/README.md) |

这三个项目的共同探索方向：如何让AI从工具变成有记忆、有个性的长期交互伙伴。
