# Raven Tarot

**连接 AI 对话与网页体验的塔罗抽牌 MCP。**

Raven Tarot 提供一套独立的塔罗抽牌与历史记录能力：用户可以在网页上滑动选牌，也可以让支持 MCP 的 AI 助手调用工具抽牌。网页与工具产生的记录分别保存，便于回看和区分不同来源。

产品围绕抽牌的参与感、随机性与记录的连续性设计，支持手机和桌面使用。

## 核心体验

- **网页选牌：** 输入问题、选择单牌或三牌阵，在扇形牌堆中滑动、选牌并翻开。
- **AI 工具调用：** AI 助手通过 MCP 调用抽牌工具，获得牌名、正逆位和图片链接，可继续组织自己的解读。
- **独立随机：** 每次抽牌重新打乱完整的 78 张牌，并独立决定正逆位；同次抽取不会出现重复牌。
- **历史回看：** 记录问题、时间和完整牌面结果，按时间从新到旧展示。
- **同步与缓存：** 网页结果保留浏览器副本并同步到 SQLite；网络不可用时可查看缓存，后续打开历史页或完成抽牌时重试同步。

服务专注于抽牌与记录，解读由接入的 AI 客户端组织。

## 产品设计

### 网页和工具，各自适合不同的使用场景

网页使用深靛蓝、暖白和金色，配合扇形牌堆与翻牌交互，让用户亲自选择牌的位置。MCP 则把抽牌能力带进已有的 AI 对话，支持在聊天中直接获得牌面结果。

两个入口分别保存记录，让交互方式和记录来源保持清楚。

### 将抽牌过程与模型生成分开

网页使用浏览器安全随机接口，MCP 使用 Python 的安全随机能力完成洗牌和正逆位。模型通过工具取得抽出的牌，围绕这些明确结果继续回应。

### 让记录能够连续使用

网页历史兼顾本地缓存与服务器保存。记录沿用唯一编号，重复同步不会新增相同记录；工具抽牌在记录成功保存后返回结果，方便之后回看。

## MCP 工具

### `draw(positions, question)`

抽取单牌或三张牌。

- `positions`：1 个或 3 个不重复的位置，取值范围 1–78，按输入顺序返回。
- `question`：本次提问，去除首尾空白后为 1–100 字。
- 返回牌的位置、牌名、正逆位和图片链接，并保存本次记录。

```json
{
  "positions": [7, 26, 78],
  "question": "今天怎样开始？"
}
```

### `history(limit=10)`

查询最近的 MCP 抽牌记录，按从新到旧排列。默认返回 10 条，最多 50 条。

## 技术实现

Python、MCP Python SDK、SQLite，以及 HTML / CSS / JavaScript。浏览器抽牌在前端完成，MCP 抽牌在服务端完成。
