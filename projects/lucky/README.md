# Lucky 的小窝

Lucky 是一只住在像素房间里的虚拟橘猫。你可以在网页里喂它、梳毛、抱抱，也可以通过 AI 助手和它互动。网页与助手连接同一只猫，共享心情和长期保存的互动记录。

它会随着时间吃饭、休息和换位置。产品围绕轻松陪伴设计，没有每日打卡，也没有健康或饥饿惩罚。

## 网页与助手，共用一只猫

MCP 是让 AI 助手调用外部工具的一种连接方式。Lucky 提供 HTTP MCP 接口，让陪伴可以发生在网页里，也可以发生在与助手的对话中。

- **状态一致：** 同一部署中的网页和 MCP 共用心情、活动、位置与互动记录。
- **互动互通：** 网页里的陪伴会进入助手可读取的历史，助手的互动也会出现在网页动态中。
- **记录保留：** 保存每次互动的参与者、动作和时间，方便回看。
- **查看不打扰：** 打开网页、查询状态或翻阅历史不会刷新最后陪伴时间。

## 五种陪伴方式

| 互动 | 动作值 | 体验 |
| --- | --- | --- |
| 喂食 | `feed` | 给 Lucky 倒猫粮 |
| 梳毛 | `groom` | 帮 Lucky 梳理毛发 |
| 抱抱 | `hug` | 抱一抱 Lucky |
| 逗猫 | `play` | 拿出逗猫棒陪它玩 |
| 撸猫 | `pet` | 摸摸 Lucky |

实际互动会改变心情，并返回当下的反应和状态。

## 三个 MCP 工具

| 工具 | 用途 |
| --- | --- |
| `get_lucky_status` | 查看心情、位置、活动与房间时段 |
| `interact_with_lucky` | 执行五种互动之一，并保存记录 |
| `get_lucky_history` | 查看长期保存的互动历史 |

通过页面内的连接说明，可以将 Lucky 接入支持 HTTP MCP 的客户端。

## 日夜与心情设计

房间按北京时间变化：06:00–16:00 是白天，16:00–17:00 是黄昏，17:00–次日 06:00 是夜晚。Lucky 会自主吃饭、休息和换位置，不需要一直打开网页。

连续 72 小时无人陪伴后，心情才会缓慢下降，最低停在 45。一次陪伴就能回暖；持续互动时，它会变得开心、兴奋，最后舒服地犯困。
